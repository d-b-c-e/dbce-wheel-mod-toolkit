SupportsPov true / Ready false. Claude independently rebuilt all seven suites

and Woden have installed the originally tested bytes and passed muted routes. See
that branch's `docs/NATIVE-48-FLEET-CANDIDATE.md`. The 55-export
experimental external API is not included.
